## 📌 사용 방법

1. 첫 화면의 텍스트 인풋에 할 일을 입력하고 **추가하기** 버튼을 클릭하거나 **Enter** 키를 눌러 할 일을 추가합니다.
2. 추가된 할 일의 **제목**을 클릭하면 상세 화면으로 이동합니다.
3. 상세 화면에서 **메모**와 **이미지**(1장)를 추가할 수 있습니다.
4. 할 일 완료 처리는 **첫 화면** 또는 **상세 화면**에서 체크박스 아이콘을 클릭해 처리합니다.
5. 할 일을 삭제하려면 상세 화면에서 **삭제하기** 버튼을 클릭합니다.
6. 완료된 할 일의 체크박스를 다시 클릭하면 **할 일 목록으로 되돌릴** 수 있습니다.

### 이미지 업로드 제약 조건

- 파일 크기: **5MB 미만**
- 파일명: **영문, 숫자, 특수문자(. _ -)** 만 허용 (한글 파일명 불가)

## 🌐 API

외부 REST API를 사용하며, 고정된 `tenantId`로 모든 사용자가 동일한 데이터를 공유합니다.

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/items` | 할 일 목록 조회 |
| POST | `/items` | 할 일 추가 |
| GET | `/items/:id` | 할 일 상세 조회 |
| PATCH | `/items/:id` | 할 일 수정 (메모, 완료 상태, 이미지) |
| DELETE | `/items/:id` | 할 일 삭제 |
| POST | `/images/upload` | 이미지 업로드 |
